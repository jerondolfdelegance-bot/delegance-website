# Delegance website

Static site for https://delegance.app (Cloudflare Pages, no build step).

- `index.html` home page · `privacy.html` privacy policy (needed for Meta/Google/LinkedIn app registration)
- `_headers` security headers · `404.html` · `robots.txt` · `sitemap.xml` · `favicon.svg` · `og.jpg`

The Delegance app itself (posting + Front Desk + AI replies) is planned separately.
